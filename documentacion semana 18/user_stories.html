🔐 Autenticación y Gestión de Perfil
US-1
Registrarse en la aplicación
Autenticación
Como visitante nuevo, quiero registrarme en RoomTracker para acceder a todas las funcionalidades.
Para poder usar la aplicación de forma personalizada y guardar mis preferencias.
Criterios de Aceptación
  • Puedo ingresar correo electrónico y contraseña
  • La contraseña debe tener mínimo 8 caracteres
  • Se valida que el correo sea único en el sistema
  • Se envía email de confirmación
  • Puedo acceder a la app tras confirmar email
Prioridad: Alta

  • Se validan las credenciales contra la base de datos
